# Foto Desa Ciperna

Folder ini untuk foto asli Desa Ciperna yang akan tampil di homepage.

## Cara memakai

1. Simpan foto sebagai `hero-desa.jpg` di folder ini.
2. Ukuran disarankan: 1200x900 px (landscape 4:3), maksimal 500 KB.
3. Restart tidak diperlukan — cukup refresh halaman.

| File             | Dipakai di            |
|------------------|-----------------------|
| `hero-desa.jpg`  | Visual utama hero     |

## Fallback

Selama `hero-desa.jpg` belum ada, homepage otomatis menampilkan
ilustrasi gradien profesional (SVG + CSS) — bukan foto palsu.
Jangan mengklaim ilustrasi tersebut sebagai foto Desa Ciperna.
